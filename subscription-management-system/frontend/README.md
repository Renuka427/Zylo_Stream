# Frontend - Subscription Management System UI

React 18 + Vite single-page application built with Tailwind CSS, Framer Motion, and React Router.

## Theme & Design Tokens
Our designated visual system is **Cherry Red + Champagne**:
- Champagne background: `#F5E9D5` (`bg-champagne`)
- Ivory cards: `#FFFAF2` (`bg-ivory`)
- Cherry red: `#C41E3A` (`text-cherry`, `bg-cherry`)
- Dark cherry: `#791D32` (`text-cherry-dark`, `bg-cherry-dark`)
- Champagne gold: `#D6B779` (`text-champagne-gold`)
- Espresso text: `#292321` (`text-espresso`)
- Warm stone borders: `#E5D4B8` (`border-stone-warm`)

Typography:
- **Inter**: Primary UI sans-serif
- **Playfair Display**: Editorial serif for headers and hero badges

## Running Locally

1. **Install Dependencies**:
   ```bash
   npm install
   ```
2. **Environment Setup**:
   ```bash
   cp .env.example .env
   ```
3. **Start Development Server**:
   ```bash
   npm run dev
   ```
4. **Build Production Assets**:
   ```bash
   npm run build
   ```
